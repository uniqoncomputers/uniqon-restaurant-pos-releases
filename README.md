## ✨ Key Features

* **High-Speed Counter Billing:** Keyboard shortcuts (`F1` to `F12`), item codes (e.g. `#101`), and lightning-fast search.
* **Smart Global Search:** Search dish names or codes across all categories with zero lag.
* **Thermal Slip Printing:** Direct silent printing for TVS RP 3230, ESC/POS 80mm & 58mm roll widths.
* **Bilingual Receipts:** Dish names print in English and Tamil with offline auto-translation.
* **Dynamic UPI QR Code:** Generates scannable Google Pay & PhonePe QR codes right on the thermal receipt.
* **Order Modes:** Full support for Dine-In (Table Management), Takeaway (Parcel), and Delivery.
* **100% Offline & Reliable:** SQLite embedded database ensures billing never stops even when internet is down.
* **Daily Closing (Z-Report):** Instant day-end summary with cash, UPI, card breakdowns, and automatic database backups.
* **Secure Licensing:** Hardware node-locked serial key activation.
